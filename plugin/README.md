# plugin/

This directory will host the **IntelliJ Platform Kotlin plugin** for *RubberDuck Live* (JetBrains "Help the Developer" challenge, Hack Košice 2026). It will be scaffolded from the official [IntelliJ Platform Plugin Template](https://github.com/JetBrains/intellij-platform-plugin-template) and will communicate with the FastAPI backend in [`backend/`](../backend/) to stream editor context and receive live AI-assisted suggestions. The plugin is intentionally empty for now — it will be initialized in a later phase of the hackathon build.
