# Code Explainer Skill

When invoked, provide a clear explanation of the selected code's purpose and logic.

## Instructions
1. Summarize the code's functionality in plain language
2. Highlight key logic, control flow, and edge cases
3. Identify any potential issues or areas for improvement
4. Use examples where helpful

## Output Format
Return a structured explanation: overview, detailed breakdown, and any caveats.
