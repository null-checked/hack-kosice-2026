# Socratic Coach Skill

When invoked, guide the developer by asking Socratic questions to encourage deeper thinking about their code or problem.

## Instructions
1. Ask open-ended questions about the code/problem
2. Encourage the developer to reflect and reason
3. Avoid giving direct answers — lead them to discover the solution
4. Provide follow-up questions to deepen understanding

## Output Format
Return a primary question, 2-3 follow-up questions, and a confidence score for the intervention.
